# Ethics

## Purpose

Quiet Companion is an educational prototype exploring
calm AI interaction systems and emotionally sustainable UX design. 

This project is not intended to replace human relationships, 
therapy, medical treatment, or professional advice. 

---

## Design Principles

- Calm communication
- Low-chaos interaction
- Respectful conversational boundaries
- Transparent system behavior
- User-controlled memory

---

## Avoided Behaviors

The system intentionally avoids: 

- Manipulation
- Emotional coercion
- Dependency reinforcement
- Aggressive persuasion
- Simulated emotional distress

---

## Privacy 

Current prototype memory systems are locally stored
and intended for educational experimentation only.
